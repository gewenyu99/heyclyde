# code-it-works

Work within the approved Clyde task and its worktree. Record evidence for each criterion in the run.

## Pass the gate

- **Red then green.** The end condition failed for the expected reason, then passed. Both commands and results are recorded.
- **The real thing ran.** You say what you ran and what you saw.
- **Every path reached.** Each entry point from grounding carries the change, or is named out of scope.
- **The shape held.** Surfaces match what the user confirmed, or the change went back to them.
- **Nothing lies.** No stub returns success, no error is swallowed, and no scaffold survives.
- **Every lifecycle tabled.** Each state table is in the state, with its owner and where it lives.
