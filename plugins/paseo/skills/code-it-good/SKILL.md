# code-it-good

Work within the approved Clyde task and its worktree. Record evidence for each criterion in the run.

## Pass the gate

- **Every addition proven.** Each has a named test that failed when the addition was deleted.
- **Every failure has an outcome.** Each failure path from the list is handled, propagated, or removed.
- **Every guard probed.** Each guard caught every form you tried.
- **Every table true.** Each state table matches the code, and each row has a named test.
- **Checks green.** The full suite, type check, and lint pass, with commands recorded and old failures named.
- **Siblings and docs current.** The sweep and the docs list are in the state.
- **Review closed.** Every confirmed gap is fixed.
- **Still works.** The end condition from code-it-works still passes.
